Infrastructure

Recommended platform:
Linux x86_64, Python 3.10 or newer, 16 GB RAM or more, and at least 5 GB free disk space after unpacking.

Public infrastructure:
The artifact is designed to run on a standard Linux VM on CloudLab, Chameleon, or Google Colab with persistent storage. No GPU is required.

Expected runtime:
Install and quick claim validation: under 5 minutes after dependencies are available.
Full paper rerun: approximately 3 hours on the authors' workstation. Runtime varies with CPU and storage speed.

Network:
install.sh uses pip to install Python dependencies. If network access is unavailable, preinstall the packages listed in requirements.txt.

Special hardware:
None.
